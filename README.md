One haiku about debugging, written to `/output/entry.txt` by `main.py`: three lines in the 5-7-5 syllable shape. The picture at the centre is a cursor blinking at three in the morning; the turn is that the bug was never fixed, it had only moved.

## Run it

```sh
python3 main.py
```

## The entry

> Three a.m. cursor
> blinks at code I swore I fixed
> the bug had just moved
